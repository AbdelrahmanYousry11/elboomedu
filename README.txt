موقع مركز البوم التعليمي — 3 صفحات
================================

التشغيل في Visual Studio Code:
1) فك ضغط ملف elboom-website.zip.
2) افتح VS Code واختر File > Open Folder وحدد فولدر elboom-website.
3) افتح index.html ثم كليك يمين > Open with Live Server.
   أو افتح index.html بالنقر المزدوج من الملفات، وسيعمل الموقع مباشرة.

الصفحات:
- index.html   = الرئيسية، فيها عنوان المركز وشريط صور يتحرك ببطء.
- about.html   = نبذة عنا + صورة السفينة kuw1 + زر تواصل معنا.
- contact.html = الإيميل وأرقام الهاتف وحقوق النشر.
- style.css    = كل تصميم الموقع والتجاوب وحركة الصور.
- assets/      = صورك الأصلية والشعار.

التعديل:
- لتغيير النصوص افتح ملف الصفحة المطلوب وعدل الجملة مباشرة.
- لتغيير اللون الأزرق، افتح style.css وعدل متغيرات :root في أول الملف.
- لتغيير سرعة الصور: ابحث في style.css عن 42s وغيّرها (مثلاً 60s أبطأ).
- لتغيير الصور: استبدل الملفات داخل assets مع الحفاظ على أسمائها.

لا يحتاج المشروع إلى قاعدة بيانات أو Backend أو تثبيت حزم.
خط Cairo يتم تحميله من Google Fonts إذا كان الإنترنت متاحًا، وإلا يستخدم خطًا بديلًا.
